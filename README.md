# Nomad

An experimental web crawler to map & visualise the connections between domains.

[![demo video](https://img.youtube.com/vi/-Yii_hK8Jyg/0.jpg)](https://www.youtube.com/watch?v=-Yii_hK8Jyg)

Most crawlers are created to search the depth of websites to find everything indexable, Nomad is specifically optimised for breadth, only requesting the root page (`/`) for each domain that it finds.

**WARNING:** *There is potential that websites could flag your connection and block you (probably IP ban) for using this.*
